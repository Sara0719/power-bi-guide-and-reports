1. Upload Data

Just upload a file with an Activity (name) column and Start / End date columns — no manual setup needed. Activities that share a software build (auto-detected from the activity text, e.g. "SWB 1.0" or "Build 2.1", or from a dedicated Software Build column if present) are automatically consolidated onto a single row, in sequence; activities without a detected build share one general row. Rows where Start equals End are drawn as milestone diamonds, and activities named FAT, SA or SAT are automatically colored as gate reviews (green / yellow / gray) regardless of build. Optional Predecessors / Successors columns (comma or semicolon separated Activity IDs) draw dependency lines.
